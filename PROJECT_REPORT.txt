DATABASE
--------
Database file:
  C:\Users\Admin\Documents\website\data\micro-dilemma.sqlite

The SQLite database stores registered account records and password hashes,
dilemmas, votes, student verification requests, and payment records. Passwords
are stored as hashes, not as plain text. Public dilemma feed responses do not
show the author account details. The owner API key is required for confidential
owner records.

HOW TO START THE WEBSITE AND BACKEND
------------------------------------
Open PowerShell and enter:
  cd C:\Users\Admin\Documents\website
  & "C:\Program Files\nodejs\node.exe" backend.js

Keep that PowerShell window open. Then visit http://localhost:5000/ in a browser.
The frontend uses the backend API at /api automatically.

SUPPORTING CONFIGURATION
------------------------
package.json lists the backend dependencies and start commands.
.env contains private backend settings and secret keys. Do not share or publish it.
README.txt contains setup and deployment notes.

This is a local development setup. Other people cannot access the local website
from the internet until it is deployed to a public hosting service.
